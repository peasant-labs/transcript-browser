# Security policy

## Supported versions

This project is pre-1.0. Only the latest published release of
`@peasant-labs/transcript-browser` receives security fixes. The current release
is `0.0.5`; older releases are unsupported.

## Reporting a vulnerability

Please do not open a public issue or discussion for a suspected vulnerability.
Instead, use GitHub's private vulnerability reporting:

1. Open this repository's **Security** tab.
2. Select **Advisories** and then **Report a vulnerability**.
3. Include affected versions, impact, reproduction steps or a proof of concept,
   and any suggested mitigation you have.

If **Report a vulnerability** is not available, the repository maintainers must
enable private vulnerability reporting in the repository settings before this
route can be used. Until it is enabled, avoid publishing vulnerability details
and contact a repository maintainer through their GitHub profile to request a
private reporting channel.

## What to expect

Maintainers will acknowledge the report when they are able, assess its impact
and reproducibility, and keep discussion in the private advisory. This is a
small project, so no fixed response or resolution deadline is promised and
there is no bug bounty program.

When a fix is ready, maintainers will coordinate release and disclosure with
the reporter. Details will normally remain private until users can update,
unless earlier disclosure is necessary to protect users.
